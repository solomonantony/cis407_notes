Key Concepts
•	render_template('home.html')  —  Flask looks for the file in the templates/ folder automatically.
•	Jinja2 is Flask's built-in templating engine. It lets you embed Python expressions inside HTML using {{ }} for values and {% %} for logic.
•	We are not using Jinja2 features yet — but the engine is already active.
